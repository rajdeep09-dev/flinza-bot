Turn Your Phone into a 4G/5G Residential Sending Node

Mobile carrier IPs have the highest sender reputation in the world. Gmail & Outlook rarely flag cellular IPs.

1. Install Mobile Proxy App

• Android: Install Every Proxy (Free on Google Play) or Proxy Server. Turn on HTTP/SOCKS toggle.
• iOS / iPhone: Use Potatso or Shadowrocket with local forwarding.

1-tap turns your phone's 4G/5G data into an outbound proxy server.
2. Bypass Carrier CGNAT (Tailscale Mesh)

Cellular carriers block inbound ports (CGNAT). Install Tailscale (100% free) on your phone and VPS.
Your phone gets a private IP (e.g. 100.x.x.x:8080) that your VPS connects to directly!

Alternative: Reverse SSH via Termux (ssh -R 8080:localhost:8080 user@vps).
3. The Airplane Mode Superpower ✈️

Whenever you toggle Airplane Mode ON for 5 seconds and OFF, your telecom carrier (Jio, Airtel, AT&T, T-Mobile) assigns your phone a completely new clean residential IP!

Unlimited fresh residential IP rotation at zero cost!
💡 Does Cloudflare provide outbound sending IPs?
Cloudflare Email Routing is inbound only. Cloudflare Workers block raw outbound SMTP socket ports (25, 465, 587) to prevent spam. However, Cloudflare Workers + Mailchannels API (free for Cloudflare domains) allows sending verified cold outreach directly via HTTP API!

Turn Phone into a 24/7 Rotating Mobile Proxy (No Root)

Step-by-step setup using Localtonet persistent reverse tunnels
Why Mobile Carrier IPs? Cellular IP addresses (Jio 5G, Airtel 5G, AT&T, T-Mobile) are shared by thousands of real mobile phone users via CGNAT. Spam filters like Google Workspace, Office 365, and Yahoo practically never blacklist mobile IPs, ensuring maximum inbox deliverability!

Step 1: Install Localtonet & Proxy on Your Phone

1. Download and install the Localtonet app on your Android phone (from Google Play or localtonet.com).
2. Install any free local proxy server app, such as Every Proxy or Proxy Server from Google Play.
3. Open Every Proxy, turn ON the SOCKS5 toggle (default port is usually 1080).

Step 2: Create a Reverse TCP/SOCKS5 Tunnel

1. Log into your Localtonet Dashboard.
2. Go to My Tunnels → Create Tunnel.
3. Select TCP / SOCKS5 protocol.
4. Set Local IP to 127.0.0.1 and Local Port to 1080.
5. Start the tunnel! Localtonet gives you a public Server Host (e.g. prx-us-1.localtonet.com) and an assigned Port (e.g. 12345).

Step 3: Copy Tunnel Credentials into Flinza

1. Paste the Tunnel Host (e.g. prx-us-1.localtonet.com) and Port into the form above.
2. Select SOCKS5 protocol.
3. Enter any Auth credentials if you enabled basic auth in Localtonet.
4. Click Test Connection to verify live packet routing through your phone's 5G network!

Step 4: Enable 1-Click Airplane Mode IP Rotation ✈️

1. On Localtonet dashboard or using MacroDroid (free on Play Store), create an action to cycle Airplane Mode for 5 seconds when an HTTP webhook is received.
2. Paste your Localtonet Webhook URL into the IP Rotation Webhook URL field.
3. Now, whenever you click 🔄 Rotate IP in Flinza, your carrier assigns a brand-new pristine residential IP automatically!

24/7 Stability Guarantee: Once saved, Flinza's backend daemon pings and maintains the Localtonet tunnel continuously in SQLite. You can shut down your laptop browser, and all cold email outreach schedules will continue dispatching without disconnecting!
